## 자막 구조(소스에서 확인)
- 번역문 = `yumimi/script/script_scene.csv`(2,611행, 자막 있는 행 1,322) · `script_choice.csv`(선택지 168행). 열: 종류·ID(예 `C101C2.DAT-ss0-4`)·매개(`#P("soundLen", …)`)·화자·일본어 받아쓰기·**영어**. 영어 칸에 타이밍 명령 `#w(초)`·`#woff(초)`·`#off()` 등 섞임 → 번역은 영어 칸만, 명령 보존.
- 빌드 흐름: `ymm_scriptimport` → `ymm_scriptbuild` → armips `asm/SATANIME.BIN.asm`(자막 엔진 SH-2, 162KB) → discaster.
- **줄바꿈은 실행 중 동적**(build.sh 주석). 글꼴 `font/scene`(sheet.png 256×192, 16×14 칸 **160자**, 가변폭·자동 커닝, 문자표 `table.tbl` 1바이트, 0xE0~ 제어) → `fontBitmap` 4bpp(글자당 112B, 17.9KB)를 장면 시작마다 **VDP1 VRAM 0x1A800** 에 통째로 복사(`loadFont`). 팔레트 CRAM 0x600.
- ⇒ 한글 1,000~1,500음절 × 112B = 110~170KB 는 통째 적재 불가 → **자막마다 필요한 음절만 VRAM 칸에 올리는 동적 캐시**(글꼴 원본은 RAM/디스크, 1bpp 이면 음절당 28B) + 2바이트 문자 코드 처리를 자막 엔진(asm)에 추가하는 설계가 유력. ⏳렌더러(글자 → VDP1 스프라이트?) 구조·RAM 여유 확인.
- 그 밖 그림 글자: 메뉴·일시정지 메뉴·인터페이스 그림(rsrc) — ⏳한글화 범위 결정.
