# 번역 TSV 안내 (2026-10-01 2판 — 일본어 원문 기준) — `my files/tsv/yumimi_001‥005.tsv`

- 만든 도구: `tools/extract.py`. 1판(영어 원문, 16파일)은 사용자 지시로 폐기 — 원문은 **일본어 받아쓰기만**.
- 분량: 1,201행(게임 안 칸 1,320) — 대사 1,067 · 선택지 120 · 노래 7 · 가사 7 · 일본어 33,772자. 파일당 29KB 이하 5개.
- 열: **ID · 위치(장면 파일) · 구분 · 공유 · 조각 · 원문(일본어) · 번역 · 화자**. 번역은 «번역» 열만.
  - 한 행 = 음성 한 토막(칸). 원문의 `¶` = 받아쓰기 줄 구분, «ママ：» 같은 이름 머리 = 그 줄의 화자(번역에 넣지 않음).
  - **조각** = 그 칸의 자막이 화면에 바뀌어 뜨는 횟수(영문 패치의 시각 명령 #w 로 고정). ★번역은 조각 수만큼 `¶` 로 나눠 쓴다.
    - 조각 = 일본어 줄 수인 행(810)은 줄마다 옮기면 된다. 다른 행(384)은 말 흐름에 맞춰 합치거나 나눈다.
  - 공유 = 같은 칸이 게임에 나오는 횟수.
- 구분 «가사» = 노래 윗줄 카라오케 발음. 로마자를 한글 발음으로 **미리 채워 둠**(`tools/kana.py`, 거센소리 규칙 — か=카·た=타·つ=츠, 촉음 = ㅅ 받침, 장음 뺌). 원문 열엔 로마자. 검토만.
  - `< >` = 카라오케 칠해지는 구간, `{ }` = 강조 — 수·순서를 바꾸면 안 된다(검사기가 막음).
- 구분 «노래» = 같은 칸의 아랫줄 뜻 번역(+대사 조각). 조각 순서는 «가사» 행 조각과 짝.

## 표기
| 표기 | 뜻 |
|---|---|
| `¶` | 조각 나눔(수 = 조각 열) |
| `\n`(글자 그대로) | 조각 안 강제 줄바꿈(없으면 엔진이 알아서 접음) |
| ~~`+A+B+`~~ | ⛔쓰지 않음 — 경칭 옵션은 한국어판에서 뺌(사용자 2026-10-01). 한 벌만 번역 |
