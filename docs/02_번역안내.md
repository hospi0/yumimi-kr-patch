# 번역 TSV 안내 (2026-10-01) — `my files/tsv/yumimi_001‥016.tsv`

- 만든 도구: `tools/extract.py`(영문 패치 소스 `script_scene.csv`·`script_choice.csv` 의 영어 칸에서 «글 줄»만).
- 분량: 글 줄 2,248(게임 안 출현 2,706) — 대사 2,006 · 노래 119 · 선택지 123 · 영어 12,665단어. 파일당 29KB 이하 16개.
- 열: **ID · 위치(장면 파일) · 구분 · 공유 · 원문(영어) · 번역 · 화자 · 일본어(참고)**. 번역은 «번역» 열만 채운다.
  - 공유 = 같은 영어 줄이 게임에 나오는 횟수(한 번 번역하면 전부 들어감).
  - 일본어 = 그 장면 칸 전체의 받아쓰기(음성 받아쓰기라 «[…?]» 는 불확실 표시), ¶ = 줄 구분.
- 타이밍 명령(#w·#woff·#off·#slot·#kseg…)·빈 줄·주석은 TSV 에 없다 — 빌더가 원래 자리에 그대로 둔다. 한 행 = 화면 자막 한 줄(한 호흡).

## 번역에서 지킬 표기
| 표기 | 뜻 | 번역 |
|---|---|---|
| `\n`(글자 그대로) | 게임 안 줄바꿈 | 필요한 자리에 그대로 둔다(한 줄이 너무 길면 넣어도 됨 — 줄 폭은 빌더가 검사) |
| `+A+B+` | 경칭 옵션: A = 경칭 보이기, B = 숨기기 | `+사쿠라코 짱+사쿠라코+` 처럼 두 벌 모두 번역, `+` 세 개 유지 |
| `<…>` | 노래 가사 로마자(카라오케) | 그대로 두거나 한글 음역 — ⏳사용자 결정 |
| `{…}` | 괄호 글자(외계어 등 이름 표시) | 괄호 유지 |
| `―` | 말 끊김 대시 | 유지 |

- ⏳줄 폭(화면 한 줄 칸 수)·글자 공급(한글 음절 수)은 자막 엔진 한글화 설계 뒤 빌더가 검사.
